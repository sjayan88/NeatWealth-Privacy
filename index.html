Privacy Policy

Effective date: 8 August 2026  ·  Last updated: 8 August 2026

This Privacy Policy governs the manner in which the NeatWealth application (the “Application”) handles information belonging to its users (each, the “User”). The Application has been designed in accordance with the principle of data minimisation: it does not collect, store, transmit, process, or share any personal data. All information entered by the User remains exclusively on the User’s device.

1.Information Not Collected

The Application does not collect, and the developer does not have access to, any of the following:

  • Personal identification information;
  • Financial data or transaction history;
  • Device identifiers, advertising identifiers, or usage analytics;
  • Location data or contact information.

The Application contains no accounts, no advertising, and no third-party tracking or analytics frameworks of any kind.

2.Data Storage

All data entered into the Application is stored locally on the User’s device by means of the device’s local database. Such data is not transmitted to, nor stored upon, any server, cloud service, or third party at any time.

3.Internet Access

The Application operates entirely offline. It establishes an internet connection for a single, optional purpose only: where the User elects to use the currency conversion feature, the Application retrieves foreign exchange reference rates from a publicly available exchange-rate service (exchangerate-api.com). Only a three-letter currency code (for example, “INR”) is transmitted in such a request. No personal, financial, or identifying information is transmitted at any point.

4.Backups and Exported Files

Any backup file (in .db format) or exported data file (in CSV format) generated by the Application is created and stored on the User’s device. Such files are transmitted only to destinations expressly selected by the User (for example, the User’s own cloud storage, electronic mail, or messaging application). The Application does not upload, synchronise, or transmit such files automatically or without the User’s direct instruction.

5.User Responsibility

The User is solely responsible for the security of the User’s device, the User’s application PIN or biometric authentication, and any backup or exported files the User creates. The developer accepts no responsibility for loss of data or for unauthorised access to exported files once such files have left the Application.

6.Children’s Privacy

As the Application collects no data from any User, it is suitable for users of all ages and imposes no age-related data-processing obligations.

7.Amendments to this Policy

This Policy may be amended from time to time. Any amendment shall take effect upon publication of the revised Policy on this page and within the Application’s “Legal & Privacy” section. Continued use of the Application following any such amendment constitutes acceptance of the amended Policy.

7.Vehicle Mileage Calculations

Fuel efficiency (mileage) is calculated using the fill-up segment method, whereby the efficiency of each segment is computed as the distance travelled divided by the volume of fuel added at the subsequent fill-up. The average mileage displayed represents the arithmetic mean of the individual segment values. The first fill-up serves only to establish the starting odometer reading, and its fuel volume is excluded from the calculation. Readings falling outside a realistic range (2 to 100 km/L) are excluded automatically. All results are indicative; actual efficiency depends upon driving conditions, load, and other factors.
